## SEO Checklist

### Technical SEO
- [ ] robots.txt configured
- [ ] sitemap.xml generated
- [ ] Canonical URLs set
- [ ] Mobile-friendly
- [ ] HTTPS enabled

### On-Page SEO
- [ ] Title tags (50-60 chars)
- [ ] Meta descriptions (150-160 chars)
- [ ] H1 per page
- [ ] Alt text on images
- [ ] Internal linking

### Performance
- [ ] Core Web Vitals passing
- [ ] Fast TTFB
- [ ] Compressed assets
