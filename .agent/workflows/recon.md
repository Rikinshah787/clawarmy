1. Read the instructions in `agents/recon/SKILL.md`.

## Quick Commands

```
# Mobile-first audit
/recon "Audit the landing page for mobile-first responsiveness"

# Touch optimization
/recon --mode=touch "Check touch target sizes and interaction patterns"

# PWA conversion
/recon --mode=pwa "Suggest steps to convert this web app into a robust PWA"
```
