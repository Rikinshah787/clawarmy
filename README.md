# 🦀 ClawArmy: The AI Specialist Command Center

[![Vercel Deployment](https://img.shields.io/badge/Vercel-Deployed-black?style=for-the-badge&logo=vercel)](https://clawarmy.vercel.app)
[![Ecosystem](https://img.shields.io/badge/Ecosystem-Antigravity-red?style=for-the-badge)](https://github.com/vudovn/antigravity)

**ClawArmy** is a premium, tactical "Mission Control" platform for designing, deploying, and synchronizing AI Agent Specialists (Antigravity Skills). Built for the next generation of agentic workflows, it allows you to compose elite agent squads and inject them directly into your development environment with zero friction.

---

## 🛰️ Key Intelligence

### 🧬 Smart Persona Composer
Design your perfect agent. Mix and match traits, define core instructions, and assign business values (MVP, Elite, Special Ops) to tailor your AI's tactical approach.

### ⚓ Universal Sync Hub
Stay permanently connected. Download the **Sync Hub Client** (`.bat`) and run it in your project root. It establishes a persistent heartbeat with the ClawArmy marketplace, automatically pulling every new agent specialist into your IDE every 5 minutes.

### ⚡ One-Click Terminal Install
Need a specialist now? Every agent in our marketplace comes with a **Magic Mission Link**. Click the icon, paste the one-liner into your terminal, and watch the agent deploy instantly.

### 🛡️ Mission-Ready Aesthetic
A high-impact, "Command Center" UI featuring tactical grid overlays, targeting reticles, and chromatic micro-animations designed for elite developers.

## 🛠️ Tactical Deployment

### Local Setup
1. **Clone the Command Center**:
   ```bash
   git clone https://github.com/Rikinshah787/clawarmy.git
   cd clawarmy
   ```
2. **Install Dependencies**:
   ```bash
   npm install
   ```
3. **Ignite the Center**:
   ```bash
   npm run dev
   ```

### ⚓ Using the Sync Hub
1. Download `clawarmy-sync.bat` from the dashboard.
2. Place it in the root of your target project.
3. Run the script and select `Mode [2]` for **Auto-Sync Heartbeat**.
